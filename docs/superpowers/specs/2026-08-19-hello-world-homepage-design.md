# Hello World 个人首页设计规格

## 目标

在空项目中构建一个 Vue 3 + TypeScript 单页个人网站。网站当前不服务特定求职、商业或社交目的，因此内容保持真实、开放和可扩展，不虚构个人经历、项目或联系方式。

首页主标题固定为 `Hello World`。整体采用用户确认的“横向终端”方向：高对比深色界面、终端式信息层级和由 GSAP ScrollTrigger 驱动的桌面横向滚动叙事。

## 页面内容

页面依次包含五个章节：

1. `00 / ENTRY`：主标题 `Hello World`，说明这是一个尚未被定义的个人主页。
2. `01 / ABOUT THIS PLACE`：解释网站保持开放、不急于定义主题。
3. `02 / NOW`：仅展示“学习、记录、构建”三种当前状态，不虚构具体履历。
4. `03 / PRINCIPLES`：展示“保持好奇、先做再说、留点空白”三条原则。
5. `04 / END`：以 `To be continued.` 收束，并提供回到顶部操作。

顶栏显示域名、当前章节和滚动进度。页脚保留域名与版权信息。ICP备案号在获得真实编号前不展示；内容配置提供可选字段，后续填入真实编号后才渲染并链接至工信部。

## 视觉系统

- 主背景：近黑中性绿色，避免蓝黑或单一绿色占满页面。
- 主文字：偏冷白色，保证正文至少达到 WCAG AA 对比度。
- 强调色：荧光绿用于状态和进度，珊瑚橙用于章节编号和关键提示。
- 字体：英文标题和数字使用可随项目打包的开源等宽字体；中文正文使用清晰的中文无衬线字体栈。
- 图形资产：采用一张遵循 Unsplash License 的授权图片，经裁剪、缩放与珊瑚色信号编辑后作为“信号场”纹理，并在项目中保留来源说明；它是装饰图，使用空 `alt`，不承载信息。
- 形状：以直线、网格、坐标和大字号排版为主，不使用大圆角卡片、渐变光球或嵌套卡片。
- 所有交互目标至少为 44×44 像素，保留清晰的键盘焦点样式。

## 响应式布局

### 桌面端（宽度不小于 768px，且未请求减少动态效果）

- 首屏占据一个稳定的 `100dvh` 视口。
- 进入故事区后固定故事舞台，纵向滚动驱动内部内容轨道从右向左移动。
- 每个章节至少占据可读宽度，长文行长控制在约 60～75 个字符。
- 顶栏进度随 ScrollTrigger 进度更新，不通过颜色单独表达状态，同时显示章节编号。

### 移动端

- 不固定舞台，也不要求横向手势。
- 五个章节按自然纵向顺序排列，避免横向溢出。
- 使用轻量的进入视口揭示效果，不改变阅读顺序。
- 动态视口使用 `dvh`，导航和回顶按钮避开安全区。

### Reduced motion

- 当 `prefers-reduced-motion: reduce` 生效时，停用 pin、scrub、视差、呼吸和文字位移动画。
- 页面在任何屏幕宽度下回退为完整的纵向文档，所有内容立即可见。
- 回到顶部使用即时滚动，不启用平滑滚动。

## 动画设计

使用用户指定的 GSAP ScrollTrigger，并遵守以下实现约束：

- 在应用入口集中调用一次 `gsap.registerPlugin(ScrollTrigger)`。
- 首屏使用 GSAP 时间线编排标题、说明和信号纹理入场。
- 横向故事使用顶层 tween，动画内部轨道而不是被 pin 的舞台元素。
- 横向位移使用 `ease: "none"`，`scrub` 与纵向滚动绑定，不在同一触发器中混用 `toggleActions`。
- 结束距离根据轨道实际 `scrollWidth - viewportWidth` 计算，并启用 `invalidateOnRefresh`。
- 字体和图片加载完成后调用 `ScrollTrigger.refresh()`。
- 在 Vue 组件卸载时通过 `gsap.context().revert()` 和 `gsap.matchMedia().revert()` 清理动画与触发器。
- 生产环境不启用 markers。

## Vue 架构

- `src/App.vue`：页面语义结构和章节组装。
- `src/components/SiteHeader.vue`：域名、章节状态、滚动进度和跳转入口。
- `src/components/HeroSection.vue`：首屏标题、说明和信号纹理。
- `src/components/HorizontalStory.vue`：桌面横向轨道及移动端纵向容器。
- `src/components/StoryPanel.vue`：单个语义章节，接收编号、标题和内容。
- `src/components/SiteFooter.vue`：回顶、域名、版权和可选备案信息。
- `src/content/home.ts`：集中保存可编辑文案和站点元数据。
- `src/composables/useHomeMotion.ts`：创建、刷新并清理 GSAP 动画。
- `src/lib/gsap.ts`：注册 GSAP 插件并导出已配置实例。
- `src/styles/`：设计令牌、全局样式、响应式和 reduced-motion 规则。

页面没有后端请求、表单或持久状态。动画是渐进增强：即使 JavaScript 或 GSAP 未运行，文档仍保持可读。

## 可访问性与 SEO

- 使用 `header`、`main`、`section`、`footer` 等语义元素，并保持连续的标题层级。
- 提供“跳到主要内容”链接和键盘可操作的回顶按钮。
- 装饰图片使用空替代文本，所有功能性图标使用 Lucide 并带可访问名称。
- 页面标题为 `Hello World`，描述为“一个尚未被定义、持续生长的个人主页”。
- 设置中文文档语言、规范 viewport 和主题色。
- 不添加虚假的结构化个人资料、社交账号或联系方式。

## 测试与验证

实现采用测试驱动流程：先编写失败测试并确认失败原因，再写最小实现使其通过。

- 组件测试：首页正确渲染五个章节、唯一主标题、回顶操作和可选备案字段。
- 内容测试：章节编号唯一且顺序稳定，未填写备案号时不渲染备案链接。
- 动画测试：横向距离计算正确，动画清理函数在卸载时执行，reduced-motion 分支不创建 pin。
- 构建验证：运行类型检查、单元测试和生产构建。
- 浏览器验证：桌面与移动视口截图，检查无横向溢出、无内容遮挡；实际滚动验证 pin、scrub、进度和回顶行为。
- 动效验证：额外验证 `prefers-reduced-motion` 下内容完整、无固定或滚动绑定动画。

## 不在本次范围

- 后台内容管理系统、文章详情页、登录、评论和数据库。
- 联系表单、邮件服务和访客统计。
- 虚构的项目案例、个人履历或社交链接。
- 尚未取得的 ICP 或公安备案编号。
